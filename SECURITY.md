# Security reports

Send suspected vulnerabilities privately to hello@driftverk.com. Include the
version or commit, affected component, prerequisites, impact and a minimal
reproduction using test data. Do not attach credentials or customer data.

Do not open a public issue with an exploit or sensitive details before the
maintainers have assessed the report. Coordinate disclosure with maintainers.
There is no guaranteed response time or security support SLA for the community
release. Report against the latest release when possible and identify any older
affected versions.

Environment isolation requires the supported Sysbox host configuration.
A local Docker/runc test is not proof of isolation for untrusted code. Operators
are responsible for updates, TLS, host access, backups and account policy.
